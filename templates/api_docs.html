Verification API

Integrate CertVerify into your HR software, admissions portal, or ATS system. Check certificate validity instantly.

Verify a Certificate

GET /api/v1/verify/<certificate_id>/

Returns the full cryptographic proof and validity status of a certificate.

Example Request (cURL):
curl http://localhost:8000/api/v1/verify/CV-UON-000001/
Example Success Response:
{
  "found": true,
  "certificate_id": "CV-UON-000001",
  "holder_name": "Alice Wanjiru",
  "institution": "UON",
  "award": "Bachelor of Science in Computer Science",
  "chain_intact": true,
  "signature_valid": true,
  "revoked": false,
  "is_valid": true
}

Ledger Status

GET /api/v1/chain/

Returns the overall health of the hash-chain ledger (total certificates, intact vs tampered).
